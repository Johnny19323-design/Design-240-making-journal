# In-Class Activities

### 1. Proposal Consultation

This week began with the Proposal Consultation, which was a one-on-one discussion with the course teacher based on the Reflective Proposal. According to the class slides, the consultation focused on thematic focus, intended data source, approach to visualisation, and the intended impact of the work. It was presented not as a formal presentation or test, but as a focused conversation about the project direction.

In the consultation, I clarified that my project direction was moving toward exploring how local environmental data shapes people’s understanding of natural space in Aotearoa New Zealand. My notes show that I was especially interested in how public natural resources are classified, managed, and experienced through data systems, and how the DOC Campsites dataset could support this direction. I identified the dataset as a strong source because it connects nature, infrastructure, classification systems, and public information. At this stage, I was not trying to make a normal tourism tool. Instead, I wanted the project to make viewers more aware of how these places are organised through data systems, and how this organisation affects environmental experience.

This discussion helped me refine the project theme from a broad interest in environmental data into a more focused concern with mediation: how local environmental data mediates people’s understanding of nature. It also clarified that the project should not simply present campsite information neutrally, but should foreground how natural spaces are being named, organised, and made legible through administrative and digital systems.

### 2. Data Exploration

After the consultation, I spent time exploring the DOC Campsites dataset in more detail. The Week 06 overview instructed us to examine what the data source is, where it comes from, what it contains, how it is structured, and what limitations or gaps it might contain.

The DOC Campsites dataset comes from the New Zealand open data platform and is an existing public dataset rather than a dataset that I collected myself. I noted that it was static rather than live, but still strong enough to continue with because it contained fields that were useful for my project direction. In particular, I focused on campsite category, region, access method, and dog policy, as well as other practical information such as facilities and capacity. These fields immediately showed me that the dataset is less about “nature itself” and more about how natural spaces are classified and managed. This was an important realisation, because it aligned strongly with the conceptual focus I had described in the consultation.

At the same time, the dataset also revealed some limitations. It contains administrative and logistical categories, but it does not contain much about memory, atmosphere, emotion, or lived experience. This means that it privileges a system-based view of nature rather than a personal or local one. Rather than seeing this only as a weakness, I understood it as part of the project’s critical value. The gaps in the dataset helped define the project direction more clearly.

### 3. Visual Research and Precedent Study

Another in-class task this week was visual research and precedent study. We were asked to gather a curated set of visual references relevant to the project and to reflect briefly on what was interesting or useful about each one.

At this stage, I was especially drawn to screen-based, map-related, and interface-based works. I was interested in projects that did more than simply plot information, and instead framed relationships between people, place, and systems. This reinforced my direction rather than changing it. I became more confident that a web-based interactive visualisation would suit the DOC Campsites dataset, because it would allow me to combine geographic structure with filtering, classification, and user interaction.

The reference process also helped me identify an important tension in the project. If the work became too functional, it would risk becoming just another information interface. If it became too abstract, it might lose the clarity needed for viewers to understand the data. This tension became an important point for later development.

### 4. Project Planning and Skills Roadmap

The final classroom activity was project planning. We were asked to sketch out what the final product might look like, identify what we needed to learn, and outline the next steps for the project.

My consultation notes indicate that I envisaged the project as a web-based interactive visualisation tool, potentially utilising a map or a categorisation and filtering interface. I noted that the aim was not to produce a standard tourism tool, but rather to create an interface that would help the audience recognise that campsite information is also part of a broader system that shapes environmental perception. I focused particularly on the relationship between environmental data and public experience, which became central to the visual design.

From this planning stage onwards, I identified several practical skills required: handling structured data, transforming location data into interactive visualisations, building screen interfaces, and learning how to combine conceptual intent with technical implementation. This planning process brought the project into sharper focus, transforming a broad proposal into a set of visual design intentions and concrete next steps.

## Independent Study

### 1. Consultation Reflection

This week’s independent research began with a reflection on the proposal consultation session. Looking back on that discussion, the most valuable aspect was that it brought greater clarity to the conceptual focus of the project. Before the consultation, I knew I wanted to utilise the DOC campsite dataset, but this discussion prompted me to think more deeply about the reasons behind this. I gradually realised that the project should not only visualise campsites as destinations, but also explore how these locations are made comprehensible through classification, access and management systems.

This fundamentally changed my way of thinking. I no longer focused solely on how to present the dataset, but began to consider what insights the project should offer. This consultation made me more aware that my project needed to go beyond the mere conveyance of information and adopt a more critical framework. Consequently, I decided to view the dataset more consciously as evidence of an organised environmental system, rather than simply a collection of locations.

### 2. Technical Skill Building

The second independent study task was technical skill building. The course asked us to address our first priority technical gap and document what we tried and learned.

At this stage, my primary task is to learn how to work with datasets in a practical way, so as to lay the groundwork for subsequent interactive prototypes. This means I need to start understanding how to read structured CSV data, how to identify useful fields, and how to translate these fields into visual or interactive elements. Even before building polished prototypes, this technical work has already helped me view the project from a whole new perspective. Every technical decision thus becomes a design decision. For instance, deciding which fields are most important influences the story the dataset will tell, whilst considering the possibilities of the interface affects how the audience understands the relationship between the camp and the system.

At this early stage of skill development, the focus is not on producing a final outcome, but on laying the groundwork for subsequent experiments. This has given me a clearer understanding of what I still need to learn and the specific technical requirements of the project.

### 3. Initial Concept Sketch

The final task of the independent research project was to produce preliminary conceptual sketches or rough prototypes based on the selected dataset. This week’s sketch notes demonstrate that I use drawing as a method to organise the project framework at a conceptual level. Rather than using visual means to finalise a design proposal, I prefer to use sketches to clarify the core ideas: the project’s direction, the selected dataset, the significance of that dataset, the intended form of presentation, and the content I wish the audience to understand.

The sketches highlight several key points. Firstly, they confirm that the DOC campsite dataset is the best direction to pursue further, as it organically combines nature, infrastructure, classification systems and public information. Secondly, they demonstrate that I have conceived the project as a web-based interactive visualisation rather than a static image. Thirdly, it clarifies that the project’s purpose is not merely to provide campsite information to the audience, but to shift their perception so that they view these sites as part of a designed data system.

This preliminary sketch is valuable because it integrates concepts, data sources, form and intended impact. It serves both as a planning tool and a tool for reflection, making it easier for me to view the project as a coherent direction rather than a collection of disparate ideas.

## Reflection

Week 06 was the point where the project began to move from proposal into active development. The class activities required me to test whether my initial ideas could actually be supported by a dataset, a visual direction, and a practical making plan. The Proposal Consultation was especially important, because it helped sharpen the critical dimension of the project. Instead of treating the DOC Campsites dataset as neutral information, I began to see it as a system that shapes how natural spaces are understood.

The combination of consultation, data exploration, visual research, and planning made this week especially productive. It did not yet result in a finished prototype, but it established the framework for everything that followed. Most importantly, it confirmed that the project would need to balance two things at once: practical clarity and conceptual depth. That tension became the foundation for the later development of the project.
